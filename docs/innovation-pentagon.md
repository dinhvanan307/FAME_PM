## Quyết định quản lý từ bảng điểm

Phân tích của người viết. Điểm Technology bình quân là 3,28. Pilot 4 có Market 4,17 và Technology 2,33. Trước khi mở rộng, nên ưu tiên kiểm tra khả năng tích hợp và vận hành ở chính pilot này. Điểm Compliance 3,33 toàn dự án che khuất khoảng từ 1,00 ở Pilot 6 đến 5,00 ở Pilot 7. Người quản lý cần xem hồ sơ từng pilot trước khi phê duyệt rủi ro tuân thủ. Ở Pilot 5, Compliance đạt 4,60 nhưng KPI P5-08 yêu cầu ít nhất 80% danh mục đáp ứng tiêu chí ESG. Muốn đóng KPI phải có số danh mục đạt và tổng số danh mục được kiểm tra cùng kỳ.
```bash
python -m pip install -r report/requirements.txt
python -m fame_pm.portfolio --data-dir du_lieu/portfolio --download --check
python -m fame_pm.pilot_evaluation --source-dir du_lieu/portfolio
```

Lệnh cuối kiểm SHA-256 của ba PDF, tám chú thích hình, năm số tổng hợp và các đoạn bằng chứng Pilot 5. Lệnh cũng đối chiếu bản Markdown với dữ liệu nguồn của bài. Để rà lại 35 ô phiên chép, mở từng hình ở bảng trên. Dùng `python -m fame_pm.pilot_evaluation --write` sau khi cập nhật nguồn.
